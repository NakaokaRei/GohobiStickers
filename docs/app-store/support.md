# ごほうびロード サポート

毎日の「できた」にスタンプを押して、自分だけのごほうびを目指すアプリです。

## 使い方

1. ロード上の次のスタンプ位置をタップします。
2. 好きなスタンプを選び、必要ならコメントや写真を添えて保存します。
3. 旗ボタンから、ごほうびと必要なスタンプ数を設定します。
4. ロード名のメニューから、目的別のロードを追加・切り替えできます。

ホーム画面にはSmall／Mediumサイズのウィジェットを追加できます。

## iCloudの同期について

iCloud同期を利用する場合は、端末のApple AccountとiCloud設定をご確認ください。アプリの設定画面に同期状態が表示されます。通信環境を確認したうえで「今すぐ同期」をお試しください。iCloudを利用できない場合でも、端末内に保存して利用できます。

## 記録の修正・削除

記録したスタンプを長押しして編集画面を開き、修正または削除できます。iCloud上のデータの更新には同期が必要です。
